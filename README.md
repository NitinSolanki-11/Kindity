# Kindity
This website is about a NGO or Charity.

Kindity is a responsive, multi-page frontend website built using **HTML, CSS, JavaScript, and Bootstrap**.  
The project focuses on clean UI design, responsiveness, and reusable components.

This is a **pure frontend project** and does **not require any backend or database**.  
It can be run directly in a web browser.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
